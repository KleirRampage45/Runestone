// PRIORITY ISSUES
P0

Screen Reader Users Are Locked Out

Zero contentDescription attributes on any ImageView (5 dock icons, cover images). GlassSlider has no AccessibilityDelegate — sliders for text scale, button opacity, and size are invisible to TalkBack. Decorative views (AmbientGlow, Vignette, Grain, Bloom) not marked as unimportant for accessibility.

FIX: Add contentDescription to actionable ImageViews. Set importantForAccessibility=NO on decorative overlays. Extend GlassSlider with AccessibilityDelegate for value announcements.
P1

Touch Targets Below Android Minimum

Dock icon wrappers at dp(40) — below 48dp minimum. Affects all 5 navigation items. Search clear button effective hit area ~30dp. Engine filter chips borderline at ~44dp.

FIX: Increase dock item wrappers to dp(48) minimum. Expand search clear button with TouchDelegate or larger padding.
P1

MUTED_DIM Contrast Fails AA

Color.rgb(100, 95, 85) = #645F55 against #0F0E10 background yields 3.96:1 ratio — below 4.5:1 WCAG AA threshold. Used for search hints, detail panel file counts, secondary labels, settings descriptions.

FIX: Lighten to Color.rgb(120, 112, 104) = #787068 for 4.5:1 AA compliance. Run /design recolor.
P2

No Reduced-Motion Support

OvershootInterpolator used on every animTap/makeLiquid. Gear spin animation runs unconditionally. No ANIMATOR_DURATION_SCALE check or animation disable option.

FIX: Check Settings.Global.ANIMATOR_DURATION_SCALE. Add "Reduce Motion" toggle in Settings. Use /design motion.
P2

Carousel Overlay Stack Risks Frame Drops

5+ simultaneous overlay Views composited: AmbientGlowView, VignetteOverlay, GrainOverlay, BloomOverlay, DepthOfFieldController. No setLayerType(LAYER_TYPE_HARDWARE) on static layers.

FIX: Set LAYER_TYPE_HARDWARE on VignetteOverlay, GrainOverlay, and BloomOverlay. Profile frame timing on low-end devices.
