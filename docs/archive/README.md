# docs/archive

Documents in this directory are **superseded research, plans, or analyses** kept
for traceability. Anything in here describes a feature that has been
implemented, a problem that has been solved, or a research item that informed
the current design but is not itself a spec of the running system.

Do not read these as the current state of the project.

## Layout

- `implemented/` — Roadmaps, plans, and status reports for features that have
  shipped. Kept so the design history of the project is recoverable.
- `research/` — External project analyses, deep dives into other runtimes, and
  one-off investigations whose conclusions have already been applied elsewhere.
- `spec/` — Draft specifications and option checklists for features that are
  either partially implemented or still future work. Useful as a reference for
  parity tracking.

## Current, living documents

- `docs/SPARSE-PATCH-WORKSPACE.md` — describes the current in-place install
  model and is referenced by the patch pipeline.
- `docs/design/` — current design specifications (3D carousel, light theme,
  GLSurfaceView post-processing).
- Root: `README.md`, `AGENTS.md`, `DESIGN.md`, `VISION-ROADMAP.md`,
  `CHANGELOG.md`, `CONTRIBUTING.md`, `THIRD_PARTY.md`, `bugreport.md`.
